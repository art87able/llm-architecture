# LLM Architecture - Optimization in PyTorch

A Jupyter Book covering optimization techniques in PyTorch: Gradient Descent, SGD, Numerical Stability, and L1 Regularization.

## Setup

```bash
pip install -r requirements.txt
```

## Build the Book

```bash
jupyter-book build .
```

The built site will be in `_build/site/`.

To preview locally:

```bash
jupyter-book start
```
